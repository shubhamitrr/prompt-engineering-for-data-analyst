***# Week 1 - Prompt Engineering Fundamentals***



***## 1. Artificial Intelligence (AI)***



***### Definition***

***Artificial Intelligence (AI) is a technology that enables computers to perform tasks that normally require human intelligence.***



***### Simple Explanation***

***AI helps computers perform tasks that normally require human intelligence.***



***### Data Analyst Use***

***AI can help a Data Analyst analyze data, find patterns, generate insights, and solve data-related problems.***



***---***



***## 2. Large Language Model (LLM)***



***### Definition***

***LLM (Large Language Model) is an AI model trained on a large amount of text to understand and generate human-like language.***



***### Examples***

***- GPT***

***- Gemini***

***- Claude***

***- Llama***



***### Key Point***

***AI is a broad technology, while an LLM is a type of AI focused mainly on understanding and generating language.***



***---***



***## 3. Prompt***



***### Definition***

***A prompt is an instruction or input given to an AI model to get a specific response or result.***



***### Example***

***"Explain SQL JOIN in simple English."***



***### Simple Flow***

***User → Prompt → AI/LLM → Response***



***### Data Analyst Example***

***"Find the top 5 products by total sales."***



***---***



***## 4. Prompt Engineering***



***### Definition***

***Prompt Engineering is the process of designing clear and effective instructions to get better results from an AI model.***



***### Example***



***\*\*Weak Prompt:\*\****

***"Analyze sales data."***



***\*\*Better Prompt:\*\****

***"Analyze the sales data and find the top 5 products by total sales."***



***### Data Analyst Use***

***Prompt Engineering can be used for:***

***- SQL queries***

***- Excel formulas***

***- Python/Pandas***

***- Data Cleaning***

***- Power BI***

***- Business Insights***



***---***



***## 5. Prompt Structure***



***### Definition***

***Prompt structure is the organized way of writing a prompt by including the information and instructions needed to get the desired output.***



***### Basic Structure***



***\*\*Role → Task → Context → Constraints → Output Format\*\****



***### Example***

***\*\*Role:\*\* You are a Data Analyst.***  

***\*\*Task:\*\* Find the top 5 products by sales.***  

***\*\*Context:\*\* Dataset contains Product, Sales and Profit columns.***  

***\*\*Constraint:\*\* Use only the provided data.***  

***\*\*Output:\*\* Return the result in a table.***



***### Key Point***

***Not every prompt needs all five parts, but this structure is useful for complex tasks.***



***---***



***## 6. Clear Instructions***



***### Definition***

***Clear instructions are specific and unambiguous instructions that tell the AI exactly what you want it to do.***



***### Example***



***\*\*Unclear:\*\****

***"Analyze the sales."***



***\*\*Clear:\*\****

***"Calculate total sales and total profit. Find the top 5 products by sales."***



***### Useful Action Words***

***- Calculate***

***- Find***

***- Identify***

***- Compare***

***- Analyze***

***- Explain***



***### Key Point***

***The more specific the instruction, the easier it is for AI to understand the task.***



***---***



***## 7. Context***



***### Definition***

***Context is the relevant background information provided to an AI model so it can better understand the task.***



***### Example***



***Instead of:***



***"Calculate customer churn."***



***Give context:***



***"The dataset contains 5,000 customers. The Churn column contains Yes/No. Yes means the customer left."***



***### Key Point***

***Give AI the information that is necessary to understand the task. Avoid unnecessary information.***



***---***



***## 8. Few-Shot Prompting***



***### Definition***

***Few-shot prompting means giving the AI a few examples so that it can understand the pattern and follow it.***



***### Example***



***Classify sales:***



***Sales = 500 → Low***  

***Sales = 2000 → Medium***  

***Sales = 5000 → High***  



***Now classify:***



***Sales = 3500 → High***



***### Types***

***- Zero-shot → No example***

***- One-shot → One example***

***- Few-shot → Few examples***



***### Data Analyst Use***

***Few-shot prompting can help with data classification, SQL formatting, report formats, and categorization tasks.***



***---***



***## 9. Bad Prompt vs Good Prompt***



***### Bad Prompt***

***"Give me SQL."***



***This is unclear because the AI does not know what SQL query is required.***



***### Good Prompt***

***"Write a MySQL query to find the top 5 employees with the highest salary."***



***### Difference***



***\*\*Bad Prompt:\*\* Vague and incomplete.***  

***\*\*Good Prompt:\*\* Clear, specific, and gives the required task.***



***### Key Point***

***A good prompt clearly explains what you want from the AI.***



***---***



***## 10. Prompt Debugging***



***### Definition***

***Prompt Debugging means finding and fixing problems in a prompt when the AI does not give the expected output.***



***### Example***



***\*\*Problem:\*\****

***"Analyze my sales data."***



***The task is too general.***



***\*\*Improved Prompt:\*\****

***"You are a Data Analyst. Calculate total sales and profit, find the top 5 products by sales, and return the result in a table."***



***### Debugging Process***



***\*\*Find Problem → Fix Prompt → Test Again\*\****



***### Questions to Check***

***1. Is the task clear?***

***2. Is enough context provided?***

***3. Are the constraints clear?***

***4. Is the output format specified?***
